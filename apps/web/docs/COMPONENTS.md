# Components

Atomic layout: `atoms/` → `molecules/` → `organisms/` → `templates/` → `pages/`. Feature folders under
`organisms/<feature>/` use `index.ts` + `ui/` + `<feature>.config.ts(x)` + `<feature>.type.ts`.

"Slices used" lists the keys each file reads or calls (static scan). Keys marked _shared_ are collision keys (see
[STATE.md](STATE.md#key-collisions)), so the slice named is only the _last_ writer. Keys marked _missing_ exist in no
slice.

(the saturation / brightness square and hue bar, moved out unchanged); Wheel = `molecules/color/HsvWheel` (hue ring,
clockwise from red at the top, with the S / V square inside, and the chosen harmony's colours as clickable points on

echoes of its own drag steps, and the wheel's harmony scheme lives in the popover (kept across Square / Wheel).
