# Decisions

## Inferred architecture decisions (as built)

These are read from the code, not from any written record. "Status" says whether the code still follows them.

| ADR | Decision | Evidence | Status |
|---|---|---|---|

| ADR-09 | **Toolbar button configs double as keyboard commands** (`handler` + `shortcut`), matched by `useKeyboardShortcuts`. | `components/config/toolbars/*`, `createCommandSlice` | Active; `onClick` and `handler` can diverge (BUG-040) |
| ADR-10 | **Animation is a keyframe system over live Fabric objects** (props written each frame), with offline WebCodecs MP4 export and a MediaRecorder fallback. | `src/animation/*` | Active; state not persisted (BUG-010/011) |
| ADR-11 | **Static hosting** on GitHub Pages (no server). Routing: `BrowserRouter` + one build-time HTML file per public route + generated `404.html` app shell (was `HashRouter` until 2026-11-07). | `ci.yml`, `rootRouter.tsx`, `vite.config.ts`, `src/app/seo/`, `homepage` | Active; constrains sharing (Q6) |
| ADR-12 | **Loose TypeScript during migration** (`strict: false`, Fabric typed as `any`). | `tsconfig.app.json`, `src/types/fabric-*.d.ts` comments | Active; meant to be temporary |
| ADR-13 | **One themed dialog system, driven by the store.** `confirmDialog`/`alertDialog` (Dialog slice) return promises; `DialogHost` renders them on `molecules/Modal`. Store-driven so slices can warn via `get().alertDialog` without importing UI (avoids BUG-048 cycles). Native `alert/confirm/prompt` banned by a test. Fits Q11: confirms stay for actions that are not yet undoable. | `createDialogSlice.ts`, `DialogHost.tsx`, `nativeDialogs.test.ts` | Active (2026-11-06) |
| ADR-14 | **Brand tokens from the logo** (Tailwind 4 `@theme` in `index.css`: `primary` = logo blue `#0a60d6`/`#22a7ff`/`#e0f0ff`, `accent` = logo orange `#ff7f0e`, `ink`, `line`, `surface`, status, 5 text styles, tighter radius scale). UI classes use tokens; canvas chrome uses `BRAND` (`lib/theme.ts`). Tailwind `blue` is **not** remapped because palette swatches use it as paint. | `index.css`, `lib/theme.ts`, `theme.test.ts`, `docs/DESIGN.md` | Active (2026-11-06) |
| ADR-15 | **Lucide icons via one `Icon` atom** (registry `ICONS`, typed `IconName`, sized `1.2em` to follow text like the old icon font). Font Awesome CDN + npm package removed; tree-shaken SVGs instead of a 100 kB+ webfont request, and no Pro-only icons that silently rendered blank. Brand logos (not in Lucide) use generic stand-ins. | `atoms/Icon.tsx`, `noFontAwesome.test.ts`, `docs/DESIGN.md` | Active (2026-11-06) |
| ADR-16 | **One panel system + token-based dark mode.** All 14 panels render inside `templates/PanelLayout` (single header) and use shared atoms/molecules (`Select` custom popover listbox, `Slider`, `Switch`, `SegmentedControl`, `PanelSection`, `Field`…). Dark mode = `.dark` re-defines the semantic tokens; components never hard-code neutrals. ~700 neutral classes were mapped to tokens mechanically; panel controls were migrated by hand. | `PanelLayout.tsx`, `atoms/Select.tsx`, `index.css` `.dark`, `panelConsistency.test.ts` | Active (2026-11-06) |
| ADR-17 | **Text is styled from the canvas, not from store mirrors.** Text UI reads the selected text live from Fabric (`hooks/useActiveText`, canvas events) and writes only through `updateText(props, { history? })` / `setTextCase`. `updateText` gained an optional 2nd argument (backward compatible) so slider drags preview without undo steps; it styles highlighted characters while editing and clears per-character overrides on whole-box edits. The old mirror keys (`isBold`, `textAlign`, …) stay for `TextToolsHeader` until BUG-070 (removal needs approval). | `createTextSlice.ts`, `hooks/useActiveText.ts`, `TextPanel.tsx`, `textSlice.test.ts` | Active (2026-11-06) |
| ADR-18 | **Fill & shadow live in a right dock tab, not the footer.** One panel edits fill type (none / solid / linear / radial), gradient stops, geometry and the drop shadow, reading the selection from the canvas (`useSelectionStyle`) and writing through store actions with `{ history }` (preview while dragging, one undo step on release). Panel gradients use percentage units (follow resizing); the on-canvas `MultiStopGradientTool` stays for free-form handles and writes pixel units, which `readFill` also understands. | `FillShadowPanel.tsx`, `lib/fillStyle.ts`, `createShapeStyleSlice.ts` | Active (2026-11-06) |
| ADR-19 | **Color themes swap only the primary scale**, via `data-theme` on `<html>` and CSS custom properties; all other colors are derived (`var()` / `color-mix`) so light + dark × 6 themes need no per-combination values. Contrast is a test, not a review step. | `index.css`, `createSettingSlice.ts` (`COLOR_THEMES`, `applyColorTheme`), `ColorThemePicker.tsx`, `colorThemes.test.ts` | Active (2026-11-06) |
